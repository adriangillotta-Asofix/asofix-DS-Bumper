Colores

VarianteClaseUso
Default.pill--defaultEs la variante neutral. Los íconos van siempre en Material Icons Outlined a 16px.
Rojo.pill--rojoSe usa para estados de error o alertas críticas.
Verde.pill--verdeSe usa para estados de éxito o confirmación.
Amarillo.pill--amarilloSe usa para advertencias o estados pendientes.
Celeste.pill--celesteSe usa para información o estados informativos.

Tamaños

Se combinan con cualquier variante de color

VarianteClaseUso
Small.pill--smSe usa en contextos compactos, como dentro de una tabla.
Medium.pill--mdEs el tamaño por defecto.
Large.pill--lgSe usa cuando la pill necesita más presencia visual.

Highlight

Versión estática, sin estados interactivos

VarianteClaseUso
Amarillo.pill-highlight--amarilloTiene mayor énfasis visual que una pill normal. Se usa para destacar algo puntual, sin necesidad de que responda a estados de hover, focus o disabled.
Menta.pill-highlight--mentaMisma lógica que la variante Amarillo, con la paleta secundaria (teal).
Violeta.pill-highlight--violetaMisma lógica que la variante Amarillo, con la paleta primary.
