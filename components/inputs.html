// Seleccionar una opción y cerrar el dropdown
function selectOption(itemEl, triggerId, dropdownId, textId, clearId) {
  const title = itemEl.querySelector('.dropdown-item__title').textContent;
  const textEl = document.getElementById(textId);
  textEl.textContent = title;
  textEl.classList.add('select__text--filled');
  document.getElementById(clearId).style.display = '';
  itemEl.closest('.dropdown__list').querySelectorAll('.dropdown-item')
    .forEach(i => i.classList.remove('dropdown-item--active'));
  itemEl.classList.add('dropdown-item--active');
  toggleDropdown(triggerId, dropdownId);
}

// Limpiar la selección
function clearSelectDemo(event, triggerId, textId, dropdownId, clearId) {
  event.stopPropagation();
  const textEl = document.getElementById(textId);
  textEl.textContent = 'Placeholder';
  textEl.classList.remove('select__text--filled');
  document.getElementById(clearId).style.display = 'none';
  document.getElementById(dropdownId)
    ?.querySelectorAll('.dropdown-item')
    .forEach(i => i.classList.remove('dropdown-item--active'));
}

Campos

CampoClaseUso
Text Field.inputCampo de una sola línea. Es el campo de texto por defecto para la mayoría de los formularios.
Text Area.textareaCampo de texto multilínea. Se usa cuando la respuesta esperada es más larga, como comentarios o descripciones.
Select.selectCampo de selección. Abre un .dropdown con las opciones disponibles.

Tamaños

Aplican a Text Field y Select

VarianteClaseUso
Large--lgEs el tamaño por defecto, para la mayoría de los formularios.
Small--smSe usa en contextos más compactos, como filtros dentro de una tabla o una toolbar.

Estados

Mismo patrón para Text Field, Text Area y Select

EstadoClaseUso
Hover--hoverSe aplica al pasar el mouse sobre el campo.
Focus--focusSe aplica cuando el campo recibe foco (por click o navegación con teclado).
Error--errorSe usa cuando el valor no pasa una validación. Va acompañado de un texto asistivo (.input__assistive--error) explicando el error.
Disabled--disabledSe usa cuando el campo no está disponible en ese momento. Deja de ser interactivo.
Read only--readonlySe usa para mostrar un valor que no se puede editar, a diferencia de disabled no comunica que el campo esté "apagado" — sin borde, sin texto asistivo, label en --text-secondary.

Prefix, suffix y contador

Prefix/Suffix solo en Text Field. El contador aplica a Text Field y Text Area.

ElementoClaseUso
Prefix.input__prefixTexto o símbolo fijo antes del valor, como $ en un campo de monto. Solo Text Field.
Suffix.input__suffixTexto o símbolo fijo después del valor. Solo Text Field.
Contador.input__countMuestra la cantidad de caracteres usados sobre el máximo, alineado a la derecha del texto asistivo dentro de .input__assistive-row. En Text Area se muestra siempre; en Text Field es opcional.
