Variantes

VarianteClaseUso
Primary.btn--primaryEs la acción principal de una pantalla o flujo. Solo debería haber una acción primaria visible a la vez.
Danger.btn--dangerComunica una acción destructiva o irreversible, como eliminar. Usa la paleta de error para diferenciarse claramente de Primary.
Secondary.btn--secondaryTiene la misma jerarquía que Primary, pero con menor peso visual. Se usa cuando conviven dos acciones en un mismo contexto, como "Cancelar" y "Guardar".
Tertiary.btn--tertiaryEs una acción de menor jerarquía, sin borde. Se usa para acciones auxiliares que no deben competir visualmente con las principales.
Link.btn--linkEs la acción de menor jerarquía, con apariencia de texto sin subrayado (solo color). Se usa dentro de párrafos, listas, o en contextos con poco espacio.

Tamaños y estados

VarianteClaseUso
Medium.btn--mdEs el tamaño por defecto, para la mayoría de los contextos.
Small.btn--smSe usa en contextos más compactos, como toolbars o dentro de una tabla.
Icon only.btn--iconSe usa cuando el espacio es limitado y el ícono es autoexplicativo. Siempre necesita un aria-label que describa la acción.
Loading.btn--loadingSe aplica mientras el botón espera el resultado de una acción asíncrona. Reemplaza el contenido por un spinner y bloquea la interacción.
DisableddisabledSe usa cuando la acción no está disponible en ese momento. El botón deja de ser interactivo.
